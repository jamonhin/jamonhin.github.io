# Course resources

Downloadable templates for the "Confident with AI" course at
`projects/ai-course.html`.

Drop the .xlsx files here, then reference them in the COURSE array at the
bottom of that page by filename only:

    { title: "Your first real task", yt: "abc123", desc: "...", file: "module-1-template.xlsx" }

The templates currently sitting in ~/Downloads that belong to lessons:

| Downloads filename | Lesson |
|---|---|
| Slide-1-Module-1-template.xlsx | Module 1 — Your first real task |
| Module-1-Slide-3-New.xlsx | Module 1 — Your first real task |
| Module-2-Slide-4.xlsx | Module 2 — Context windows |
| Module-2-Slide-4-Extended Thinking-2.xlsx | Module 2 — Extended thinking |
| Module-2-Slide-4-MCP System Connections-3.xlsx | Module 2 — Connecting AI to your systems |
| Module-2-Slide-4-Multimodal Input-4.xlsx | Module 2 — Working with images and documents |

Rename them to something readable before committing — the filename is what
the visitor sees when they download it. Lowercase, hyphens, no spaces.
