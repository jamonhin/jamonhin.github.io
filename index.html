I'm now extending that platform into executive reporting: n8n workflows ingest HubSpot contacts and deals into an ArangoDB reporting warehouse, a read-only FastAPI service exposes the metrics over AQL, and two dashboards — an operational Master Report for the CEO and a revenue Loss Analysis — are provisioned as code in Grafana and deployed on AWS EC2.

For eThink Solutions — an award-winning Australian custom application and BI company whose clients include Lyft, GrainCorp, and DP World — I'm building a RAG system that enhances their mortgage broker CRM with document intelligence. The platform processes 150+ loan documents with 95%+ accuracy, classifies and chunks content at granular levels, maps relationships between banks, processes, and compliance requirements through a graph model, and lets staff query everything through natural conversation. Manual document lookup time has been reduced by 80%.

For an Australian no-interest loan (NILS) provider, I'm building an AI document-validation pipeline for microloan assessments. Caseworkers currently review large document packs by hand against a detailed eligibility handbook; the pipeline classifies and extracts fields from each document — native-text PDFs and image scans alike — validates them against eligibility criteria encoded as versioned, auditable decision tables, and returns a triage recommendation with cited reasons. Every extracted value is grounded against the source text, low-confidence fields are escalated for human confirmation, and the system never auto-approves. The consent rule is enforced in Postgres row-level security rather than in the interface, so nothing reaches the family without an explicit yes — and the whole thing works across eleven languages.

DocTriage — AI Document-Validation Pipeline for No-Interest Microloan Assessments

An AI pipeline that reads and validates microloan application documents against codified eligibility rules, producing an auditable recommendation for a caseworker to decide — privacy by design. Built for an Australian no-interest loan (NILS) provider, it replaces the manual review of large applicant document packs with a structured, traceable result. The pipeline ingests both native-text PDFs and image scans via OCR, classifies each document type, extracts the relevant fields per type across identity, income, banking, tenancy and supplier-quote documents, then validates them against the program's eligibility criteria encoded as versioned decision tables — each rule citing its source in the lending handbook, so every outcome is auditable. Extracted values are grounded against the document's own text, and anything low-confidence is flagged for human confirmation rather than trusted blindly. The system returns a triage outcome with human-readable reasons and a needs-review list; it never auto-approves, so a caseworker always makes the final call. Privacy is architectural: real applicant data never leaves the local environment, development and testing run entirely on synthetic applicants, and only de-identified evaluation data is persisted for quality tracking against human-reviewer decisions.
